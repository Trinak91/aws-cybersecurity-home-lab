# AWS Cybersecurity Home Lab

## Overview

This project is a hands-on cybersecurity laboratory
built using Amazon Web Services (AWS).

The goal is to learn and demonstrate:

- Cloud security
- Identity and Access Management
- Network security
- Least privilege
- Logging and monitoring
- Incident investigation
- Security documentation

## Technologies

- AWS
- VPC
- IAM
- EC2
- Security Groups
- CloudTrail
- Linux
- GitHub
